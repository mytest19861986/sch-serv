# Project Control Center

مرکز کنترل پروژه، مرجع هماهنگی وضعیت، تصمیمات، ریسک‌ها، وظایف و گزارش‌های پروژه است.

## قوانین استفاده

- این ساختار فقط برای مدیریت و مستندسازی است.
- هر تغییر مهم باید در `DECISION_LOG.md` یا `CHANGE_LOG.md` ثبت شود.
- وضعیت جاری در `PROJECT_STATUS.md` و پیشرفت مراحل در `PHASE_TRACKER.md` نگهداری می‌شود.
- ریسک‌ها و موانع در `RISK_REGISTER.md` و `BLOCKERS.md` ثبت می‌شوند.
- این مرکز جایگزین اسناد رسمی محصول و معماری نیست؛ به آن‌ها ارجاع می‌دهد.

## ارتباط با Pipeline

Pipeline از `00 Master Context` تا `18 Documentation` در `PHASE_TRACKER.md` ثبت شده است. ورود به هر مرحله باید بر اساس Gate مرحله قبل انجام شود.
